## 0. Bối cảnh & phạm vi

**Mục tiêu:** dựng khung dự án chạy được bằng `docker compose up -d --build`, chưa có tính năng nghiệp vụ.

**Trong phạm vi M0 (chỉ làm những việc dưới đây):**
- Skeleton backend FastAPI + Alembic (chưa migration nội dung).
- Skeleton frontend Vite + React 18 + TS + Tailwind + shadcn/ui deps.
- `docker-compose.yml` với 3 service core (`db`, `api`, `web`) + `caddy` reverse-proxy.
- `.env.example`, `Caddyfile`, `README.md` ngắn.
- Endpoint `GET /api/v1/health` trả `{"status":"ok"}`.
- Trang `/` (placeholder hiển thị được) và `/admin` (placeholder).
- Error format thống nhất `{"error":{"code","message"}}`.
- 1 test backend `tests/test_health.py` (bonus).

**Ngoài phạm vi M0 — KHÔNG làm (dù thấy dễ):**
- Không tạo bảng DB, không migration nội dung (để M1).
- Không OSM, không tile server, không bản đồ (để M2).
- Không auth, không register/login (để M4).
- Không upload ảnh (để M5).
- Không Pannellum (để M3).
- Không bật HTTPS thật / domain thật (để M7).
- Không seed admin (để M4).

#### 2.5 `backend/app/main.py`

```python
from fastapi import FastAPI, Request
from fastapi.exceptions import RequestValidationError
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

from app.core.config import settings
from app.routers import health


# ---- Exception chuẩn hoá theo format {"error": {"code", "message"}} ----

class AppError(Exception):
    def __init__(self, code: str, message: str, status_code: int = 400):
        self.code = code
        self.message = message
        self.status_code = status_code


app = FastAPI(
    title="KMap API",
    version="0.1.0",
    docs_url="/api/v1/docs" if settings.ENV != "production" else None,
    redoc_url=None,
    openapi_url="/api/v1/openapi.json" if settings.ENV != "production" else None,
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=[settings.FRONTEND_ORIGIN],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.exception_handler(AppError)
async def app_error_handler(request: Request, exc: AppError) -> JSONResponse:
    return JSONResponse(
        status_code=exc.status_code,
        content={"error": {"code": exc.code, "message": exc.message}},
    )


@app.exception_handler(StarletteHTTPException)
async def http_error_handler(request: Request, exc: StarletteHTTPException) -> JSONResponse:
    return JSONResponse(
        status_code=exc.status_code,
        content={"error": {"code": "http_error", "message": str(exc.detail)}},
    )


@app.exception_handler(RequestValidationError)
async def validation_error_handler(request: Request, exc: RequestValidationError) -> JSONResponse:
    return JSONResponse(
        status_code=422,
        content={
            "error": {
                "code": "validation_error",
                "message": "Dữ liệu không hợp lệ.",
                "details": exc.errors(),
            }
        },
    )


# ---- Routers ----
API_PREFIX = "/api/v1"
app.include_router(health.router, prefix=API_PREFIX)
```

> Lưu ý cho agent: chưa cần custom handler cho `Exception` (lỗi 500) — Starlette đã trả về "Internal Server Error" (không lộ stack trace trong production). Custom format cho 500 sẽ làm ở M7.

#### 3.8 `frontend/src/api/client.ts`

```ts
const API_URL = import.meta.env.VITE_API_URL ?? "/api/v1";

export type ApiError = { code: string; message: string };

export async function apiGet<T>(path: string): Promise<T> {
  const res = await fetch(`${API_URL}${path}`, {
    headers: { Accept: "application/json" },
    credentials: "include",
  });
  const body = await res.json().catch(() => ({}));
  if (!res.ok) {
    const err: ApiError = body?.error ?? { code: "unknown_error", message: `HTTP ${res.status}` };
    throw new Error(err.message);
  }
  return body as T;
}
```

```yaml
      context: ./frontend
      args:
        VITE_API_URL: ${VITE_API_URL}
        VITE_MAP_CENTER_LAT: ${VITE_MAP_CENTER_LAT}
        VITE_MAP_CENTER_LON: ${VITE_MAP_CENTER_LON}
        VITE_MAP_ZOOM: ${VITE_MAP_ZOOM}
        VITE_TILE_URL: ${VITE_TILE_URL}
        VITE_TILE_ATTRIBUTION: ${VITE_TILE_ATTRIBUTION}
    restart: unless-stopped
    expose:
      - "80"

  caddy:
    image: caddy:2-alpine
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - caddy_data:/data
      - caddy_config:/config
    depends_on:
      - api
      - web

volumes:
  pgdata:
  media:
  caddy_data:
  caddy_config:
```

> Ghi chú cho agent: theo tài liệu gốc, "3 service" là `db`, `api`, `web`. `caddy` là lớp proxy mỏng (đã có sẵn `Caddyfile` ở root) — coi như hạ tầng, không tính vào 3 service nghiệp vụ. Nếu thầy/cô muốn **đúng 3 service**, agent báo lại và chuyển Caddy ra chạy ngoài Docker.

## 5. Các lỗi thường gặp & cách xử lý

| Triệu chứng | Nguyên nhân | Cách xử lý |
|---|---|---|
| `api` báo `ModuleNotFoundError: app` | `pip install .` chạy trước khi copy `app/` | Kiểm tra `Dockerfile` — phải `COPY app ./app` **trước** `pip install .` |
| `api` exit vì `DATABASE_URL` thiếu | `.env` chưa copy | `cp .env.example .env` |
| `db` unhealthy | Password trong `.env` có ký tự `$` bị compose interpolate | Thêm `$$` hoặc đổi password tránh `$` |
| `web` trắng trang sau deploy | `nginx` không fallback SPA | Kiểm tra `nginx.conf` có `try_files $uri /index.html` |
| `curl localhost/api/...` trả `404` | Caddyfile route sai | Đảm bảo `handle /api/*` đứng **trước** `handle` chung |
| `curl localhost/` trả 502 | `web` chưa healthy | `docker compose logs web` — thường do `npm run build` fail (TypeScript strict) |
| `/admin` trả 404 | nginx thiếu fallback | Xem lại 3.15 |
| `pytest` không tìm thấy module `app` | Chạy từ thư mục sai | `cd backend && pip install -e . && pytest -q` |
| TS build fail vì alias `@/...` | `paths` chưa có trong `tsconfig.json` | Thêm `baseUrl` + `paths` (mục 3.13) |
