# M0 — Khung dự án (tuần 1, ngày 1)

Đọc trước: `docs/PLAN.md` (mục 3, 5), `docs/DECISIONS.md` (D-01, D-02, D-10, D-18).

## Làm
- Khởi tạo repo theo cấu trúc `docs/PLAN.md` mục 5 (các thư mục chưa dùng có thể để trống kèm `.gitkeep`).
- `docker-compose.yml` với 3 service `db` (`postgis/postgis:16-3.4`), `api`, `web` đúng D-01. Volume cho dữ liệu DB và `/data/media`. Log rotation theo D-18. `docker-compose.dev.yml` cho dev (mở cổng, bật CORS dev).
- `api`: `GET /api/v1/health` trả 200 và kiểm tra được kết nối DB. Entrypoint tự chạy `alembic upgrade head`. Uvicorn 1 worker, bật `--proxy-headers` (D-10). Định dạng lỗi chuẩn và handler chung không lộ stack trace (xem `docs/RULES.md` mục 4).
- `web`: Caddy phục vụ frontend build. Frontend hiển thị trang trống với router `/` và `/admin`.
- `.env.example` đầy đủ: DB, JWT secret, domain, thư mục media, `TERMS_VERSION`, `COOKIE_SECURE`, `SAT_TILE_URL`, `SAT_ATTRIBUTION`, `SAT_MAX_ZOOM`, thông tin seed admin, biến backup (để trống, dùng ở M7).
- `Makefile` với các lệnh trong `CLAUDE.md` (`up`, `down`, `logs`, `migrate`, `test`, `lint`, `e2e`, `seed-admin`). Ở M0 các test có thể chỉ là test mẫu nhưng lệnh phải chạy được.
- Cấu hình pytest dùng database `kmap_test` trong service `db`.
- Playwright cài sẵn với một test rỗng chạy được qua `make e2e`.
- `README.md` ngắn: cách chạy, cách test.

## Không làm
OSM, bảng dữ liệu nghiệp vụ, auth, bản đồ.

## Nghiệm thu
- [ ] `docker compose up -d --build` chạy sạch trên máy mới (không phụ thuộc file ngoài repo ngoài `.env`).
- [ ] `curl -i http://localhost/api/v1/health` trả 200 và có trạng thái DB.
- [ ] Mở `/` và `/admin` thấy trang; tải lại trang con không lỗi 404 (SPA fallback).
- [ ] `docker compose ps` cho thấy chỉ `web` publish cổng ra ngoài (khi dùng file compose production).
- [ ] `make test`, `make lint`, `make e2e` đều chạy và xanh.
- [ ] Gây lỗi giả trong API thì phản hồi theo định dạng `{"error": ...}`, không có stack trace.

## Báo cáo
Theo mẫu trong `CLAUDE.md`. Kèm phiên bản các thành phần đã chọn (Python, Node, Caddy, osm2pgsql nếu có).
