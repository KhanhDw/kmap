# M6 — Đóng góp đường và quản lý user (tuần 4, ngày 16–18)

Đọc trước: `docs/RULES.md` mục 2, 3, 5; `docs/DECISIONS.md` (D-03, D-08, D-11).

## Làm

**Đường (API)**
- `POST /api/v1/roads` (GeoJSON LineString, `name`, `road_type`, `terms_version`), `GET /api/v1/me/roads`, `DELETE /api/v1/roads/{id}` (xóa mềm). Kiểm tra đúng `docs/RULES.md` mục 2. Rate limit và ghi `contributor_terms` như ảnh.
- Admin: `GET /admin/queue/roads`, `POST /admin/roads/{id}/approve`, `/reject` (bắt buộc `reason`).
- `GET /roads?layer=community` trả đường đã duyệt (đã có từ M2, kiểm tra hoạt động với dữ liệu thật).
- `GET /admin/stats` cập nhật số đường chờ duyệt.

**Đường (giao diện)**
- Client `/contribute/road`: leaflet-draw **chỉ polyline** (tắt các công cụ khác), nhập tên và loại đường, hộp điều khoản (hình học đường phát hành CC0 1.0, D-03), gửi duyệt. Hiển thị lỗi tiếng Việt (ngoài vùng, quá ngắn, quá nhiều điểm).
- `/me` thêm tab "Đường": trạng thái, lý do từ chối, xóa mềm.
- Bản đồ chính: đường cộng đồng đã duyệt màu xanh lá, khác hẳn đường OSM.
- Admin `/admin/roads`: danh sách hàng chờ; xem tuyến đề xuất (đỏ) chồng lên đường OSM (xám) trên bản đồ lớn; duyệt/từ chối kèm lý do mẫu.

**Quản lý user (chỉ admin)**
- API: `GET /admin/users` (tìm kiếm, phân trang), `PATCH /admin/users/{id}` (đổi role, ban/bỏ ban), `POST /admin/users/{id}/reset-password` (sinh mật khẩu tạm hiển thị **một lần**, thu hồi mọi refresh token của user đó).
- Ràng buộc trong `docs/RULES.md` mục 3 (không tự đổi role/ban chính mình; luôn còn ≥ 1 admin).
- UI `/admin/users`: bảng user, đổi role, ban, đặt lại mật khẩu có hộp xác nhận.

## Không làm
Sửa đường, snap vào OSM, Hausdorff.

## Nghiệm thu
- [ ] Test pytest: đường 1 điểm, đường < 20 m, > 500 điểm, tự cắt nhau không hợp lệ (nếu `ST_IsValid` từ chối), đường ngoài vùng → lỗi đúng mã; đường vắt qua biên hai vùng → nhận.
- [ ] Test: luồng duyệt/từ chối đường; xóa mềm; quyền (user thường không vào queue).
- [ ] Test quản lý user: moderator gọi `/admin/users` → 403; admin không thể tự ban hoặc hạ role mình; không thể hạ admin cuối cùng; reset password thu hồi token cũ.
- [ ] E2E: user vẽ đường → admin duyệt → đường xanh hiện trên bản đồ chính của khách ẩn danh.
- [ ] Ở 360 px, `/contribute/road` vẽ được bằng cảm ứng (kiểm tra trên emulator hoặc điện thoại thật).
